Change: Introduce a user editable account alias

The identifying text on account button has been very unsatisfying because there is no straightforward way to identify an account using short-ish text that is unique, and which the user can identify with.

Our new approach is to use an account alias as text on the account buttons which the user can customize to their liking.

The default alias value is derived from the first word that appears in the display name (usually the user's first name)

The user can change this alias any time by going to the "Manage account" menu and selecting "Change alias..." which will pop a simple input dialog.
