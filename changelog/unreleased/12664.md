Bugfix: Replace icon from Remix Icon with the Font Awesome version

The Remix Icon License has restrictions preventing their icons
from being used for several use cases. There may be restrictions
on icons released even before this recent license change.

We've fixed this by using an equivalent icon from Font Awesome,
which we already have been using for several icons.

https://bugs.debian.org/1145682
