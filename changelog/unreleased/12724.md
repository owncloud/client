Change: Update Qt to 6.12.1 in the Conan build

The Conan dependency configuration now uses Qt 6.12.1. Qt 6.12 supports
macOS 14.4 and newer, so a macOS client built with Qt 6.12 or newer requires
macOS 14.4; with an older Qt, as in the Craft build, the minimum stays 13.0.
