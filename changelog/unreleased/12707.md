Bugfix: Fix a crash when Windows virtual files are hydrated or validated

The Windows virtual files plugin passed Windows a pointer from a hydration
or validation request after that request had returned, and Windows could
then crash the client while it downloaded or checked a file on demand. This
was most likely when the file had changed on the server. The plugin now
keeps only the request's keys.
