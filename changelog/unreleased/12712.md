Bugfix: Keep a moved file a move when the server can't be asked about it

When the client could not check a moved file's old location on the server, for
example because of a server error, it uploaded the file again under its new name
and deleted the old one. The file lost its history and shares, and if the
delete failed too, it was on the server twice. The client now keeps the move,
and reports the server's error if the move fails.
