Change: Find Qt and Sparkle in the CMake form both Craft and Conan provide

The build now finds Qt's LinguistTools as a Qt6 component, reads qmake's path
from `Qt6::qmake`, and includes QmlIntegration as `<QtQmlIntegration/...>`,
forms that both Craft's and Conan's Qt provide. The Sparkle updater is linked
through a `sparkle::sparkle` target: Conan's package provides it, and
FindSparkle now defines the same target for Craft. A Conan build therefore
includes Sparkle, which it used to leave out silently.
